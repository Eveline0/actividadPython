# 🚗 Actividad Colaborativa - Taller Práctico de POO en Python

## 📌 Descripción

Este proyecto corresponde al desarrollo de un taller enfocado en la **Programación Orientada a Objetos (POO)** utilizando Python.

A lo largo de la actividad se implementan diferentes ejercicios que permiten comprender y aplicar conceptos fundamentales como clases, objetos, encapsulamiento, herencia, polimorfismo, abstracción, interfaces, composición y manejo de excepciones.

---

## 🎯 Objetivos

* Comprender la estructura básica de clases y objetos.
* Aplicar encapsulamiento mediante atributos privados.
* Utilizar constructores para inicializar objetos.
* Implementar herencia entre clases.
* Aplicar polimorfismo y sobreescritura de métodos.
* Trabajar con clases abstractas e interfaces.
* Comprender la composición entre clases.
* Manejar excepciones y crear excepciones personalizadas.

---

## ▶️ Cómo ejecutar el proyecto

1. Clonar el repositorio:

```bash
git clone https://github.com/Eveline0/actividadPython.git
```

2. Ingresar a la carpeta del proyecto:

```bash
cd actividadUno
```

3. Ejecutar el programa:

```bash
python main.py
```
